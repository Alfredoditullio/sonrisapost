# Security Policy

## Scope

This policy covers **SonrisaPost** — this repository and the container
images and deployments published from it.

It does **not** cover upstream [Postiz](https://github.com/gitroomhq/postiz-app),
which this project forks. If you find a vulnerability in unmodified upstream
code, please also report it to the Postiz maintainers so other downstream
projects get the fix.

Vulnerabilities in third-party dependencies or in infrastructure operated by
self-hosters are out of scope here; report those to the relevant party.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately via GitHub's *Report a vulnerability* form on this repository's
Security tab, or by email to `security@sonrisapost.com`.

Include: affected version or commit, a description of the impact, and steps to
reproduce.

We aim to acknowledge reports within 5 business days.

## Supported versions

Only the latest release on the default branch receives security fixes.

## Disclosure

We ask for a 90-day window before public disclosure, or until a fix ships —
whichever comes first. Reporters are credited unless they prefer otherwise.
